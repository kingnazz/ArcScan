Get started in three steps

  1. 1

    Download

    Get the installer for your operating system. Windows x64, Windows ARM64, and macOS are all supported.

  2. 2

    Install

    The app is not code-signed yet, so Windows SmartScreen may warn on first launch. Choose More info, then Run anyway. On macOS, right-click the app and choose Open the first time. You can verify the SHA-256 checksum for certainty.

  3. 3

    Scan

    Press Scan. Devices appear in seconds, and the app updates itself from then on.

Frequently asked questions

Is ArcScan free?

Yes. ArcScan is free and open source. The full source code is on GitHub.

Which operating systems are supported?

Windows 10 and 11 on x64 and ARM64, and macOS with a single universal build for Apple Silicon and Intel.

Does ArcScan send my data anywhere?

No. Scans run entirely on your machine and results stay local. Nothing is uploaded. This website's only network request is a read-only check to GitHub for the latest version.

Does it need administrator rights?

No administrator rights are needed to scan, because ArcScan uses ordinary operating system networking. The installer may prompt for elevation to install for all users, like any app.

Why does my OS warn me on first run?

The installers are not code-signed with a paid certificate yet, so SmartScreen and Gatekeeper flag a new publisher. Proceed as described in the install steps, and verify the SHA-256 checksum for peace of mind.

How is ArcScan different from Advanced IP Scanner or Angry IP Scanner?

ArcScan is a modern, native, cross-platform alternative. It runs on both Windows and macOS, stays consistent between scans with ARP-verified discovery, and updates itself with signed releases.
